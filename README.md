# Joseph Wu

Personal portfolio for Joseph Wu, senior software engineer. The site covers Python platforms, AI engineering, experience, selected work, and contact.

Content lives in `src/react-app/data/portfolio.ts`. Email and phone are set there. The contact form opens the visitor's mail app with a message addressed to Joseph. It does not send mail from a server. GitHub and LinkedIn stay hidden until real profile URLs are added.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

The portrait is `public/images/joseph-portrait.jpg`. The downloadable resume is `public/resume/joseph-wu-resume.pdf`.
